02 Introduction

Intermediate control from a digital pin

An Arduino Uno output is naturally LOW at about 0 V or HIGH at about 5 V. PWM creates useful intermediate effects by controlling how long the output stays HIGH in each repeated cycle.

LEDs

Adjust perceived brightness.

Motors

Control average power and speed.

Fans

Match cooling to demand.

Waveforms

Generate repeated pulse patterns.

Key idea: the pin still switches between LOW and HIGH. PWM does not directly produce every voltage in between.

03 Core concept

Switch fast, vary the HIGH time

Pulse Width Modulation controls the average electrical energy delivered to a device by rapidly switching a digital signal ON and OFF and varying the width of its HIGH pulse.

HIGH ≈ 5 VLOW ≈ 0 V
HIGHLOWHIGHLOW
Repeated digital cycles → time

The waveform remains digital because only two electrical states are used. The time spent in each state is what changes.

04 Waveform vocabulary

Period, frequency, pulse width, duty cycle

Period, T

Total time for one complete HIGH-plus-LOW cycle.

Frequency, f

Number of complete cycles produced per second, measured in hertz.

Pulse width

The HIGH time, also called ON time, during one period.

Duty cycle

Percentage of the period for which the output is HIGH.

Frequencyf = 1 / T
PeriodT = 1 / f
Duty cycle(THIGH / T) × 100%
05 Worked computation

Find period from a 500 Hz frequency

1Given

f = 500 Hz

2Formula

T = 1 / f

3Substitute

T = 1 / 500 = 0.002 s

4Convert

0.002 s × 1000 = 2 ms

Final answerT = 2 ms

The waveform completes one full cycle every 2 milliseconds.

08 Simplified average

Estimate the average effect

Simplified modelVAVG = duty cycle (decimal) × VMAX

Given

VMAX = 5 V
Duty cycle = 50% = 0.50

Substitute

VAVG = 0.50 × 5 V

Result

Approximate average = 2.5 V

The pin is not continuously producing 2.5 V. It continues switching rapidly between approximately 0 V and 5 V.

09 Important distinction

Same average, different waveform

True analog output

May remain continuously at an intermediate voltage such as 2.5 V.

VS

50% PWM output

Alternates between 0 V and 5 V, spending half of every period HIGH.

digital PWM waveformaverage effect

LEDs and many motors respond usefully to the average effect. Smooth-voltage applications may need filtering or a digital-to-analog converter.

13 Fixed output

Drive an LED from PWM pin 9

Pin 9→220 Ω resistor→LED→GND
int ledPin = 9;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  analogWrite(ledPin, 128);
}

Value 128 is approximately 50% duty cycle, so the LED appears at an intermediate brightness.

15 Gradual change

Fade in, then fade out

void loop() {
  for (int brightness = 0; brightness <= 255; brightness++) {
    analogWrite(ledPin, brightness);
    delay(10);
  }
  for (int brightness = 255; brightness >= 0; brightness--) {
    analogWrite(ledPin, brightness);
    delay(10);
  }
}

The first loop increases the PWM value one step at a time. The second loop decreases it, producing a repeating fade.

16 Input-process-output

Map a 10-bit reading to 8-bit PWM

Potentiometer→analogRead(A0)→map()→analogWrite(9)→LED
int sensorValue = analogRead(A0);
int pwmValue = map(sensorValue, 0, 1023, 0, 255);
analogWrite(9, pwmValue);

The Uno ADC reads 0-1023. PWM output uses 0-255, so map() converts between the two ranges.

17 Hardware timers

The timer handles the repeated pulses

1Sketch

Your program chooses a pin and value.

2analogWrite()

Configures the PWM hardware.

3Timer/counter

Repeatedly counts through its range.

4Compare register

Defines when the output changes state.

5PWM pin

Switches automatically.

With an 8-bit count from 0 to 255 and a compare value near 128, the output is HIGH for about half the cycle. Hardware operation frees the processor from calling digitalWrite() for every pulse.

18 Timer-dependent behavior

Frequency depends on the selected timer

Each Arduino Uno PWM pin is associated with a hardware timer. The default frequency is generally adequate for common LED applications, while advanced systems may require direct timer configuration.

Engineering note: changing timer registers can affect Arduino timing functions and libraries. Modify timers carefully and only when the application requires it.

Too low

LED flicker or motor vibration may become noticeable.

Too high

Switching losses may increase in some driver circuits.

Best choice

Match frequency to the load and system requirements.

✓ Key takeaways

From software value to physical response

  • PWM creates an analog-like effect with a digital HIGH/LOW signal.
  • Duty cycle determines the fraction of each cycle spent HIGH.
  • The Uno commonly supports PWM on pins 3, 5, 6, 9, 10, and 11.
  • analogWrite() uses values from 0 to 255.
  • Hardware timers generate the repeating waveform efficiently.
  • LEDs, motors, fans, and cooling systems can respond to PWM.
  • Motor and fan loads require suitable driver circuitry.
  • PWM bridges programming, digital electronics, and physical control.
